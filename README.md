# Fedora Hyprland Dotfiles

This repository contains my personal Linux configuration setup built on Fedora using the Hyprland Wayland compositor. The setup focuses on performance, workflow efficiency, and deep system-level customization.

## Features

- Hyprland dynamic tiling window manager configuration
- Waybar custom modules and layout tuning
- Kitty terminal customization
- Fastfetch system identity customization
- Workflow-oriented keybindings
- Wayland-native environment optimization

## Motivation

I enjoy working with low-level Linux configuration and experimenting with system environments to improve productivity and understand how modern Linux display stacks (Wayland) function internally.

This setup reflects my interest in systems programming, embedded environments, and robotics-related Linux workflows.

## Technologies Used

- Fedora Linux
- Hyprland (Wayland compositor)
- Waybar
- Kitty terminal
- Fastfetch
- Git
