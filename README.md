# Arch Hyprland Dotfiles

A clean and highly customizable Arch Linux + Hyprland setup featuring Material You dynamic theming with Matugen, custom Waybar modules, Rofi integration, and a workflow-focused desktop experience.

## Showcase

🎥 Desktop showcase video coming soon.

## Features

* Hyprland Wayland compositor
* Dynamic Material You theming with Matugen
* Custom Waybar configuration
* Rofi application launcher
* Kitty terminal configuration
* SwayNC notification center
* Wlogout power menu
* GTK3/GTK4 theming
* Fastfetch system information
* Thunar file manager configuration

## Environment

* **OS:** Arch Linux
* **Compositor:** Hyprland
* **Terminal:** Kitty
* **Bar:** Waybar
* **Launcher:** Rofi
* **Notifications:** SwayNC
* **Power Menu:** Wlogout
* **Theme Engine:** Matugen
* **File Manager:** Thunar

## Installation

Clone the repository:

```bash
git clone https://github.com/AI-D-EN/pearce-repo.git
cd pearce-repo
```

Copy the configurations:

```bash
cp -r .config/* ~/.config/
```
